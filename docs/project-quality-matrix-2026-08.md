# Public project evidence matrix

Current objective classification for the seven public projects.

| Project | Artifact | Evidence boundary | Status |
|---|---|---|---|
| Campaign Incrementality | Flagship analysis | Randomized benchmark does not establish current campaign economics | Completed benchmark analysis |
| Marketplace Supply and Demand | Flagship analysis | Recorded trips do not measure requests, unmet demand, or driver availability | Completed measurement audit |
| MTA Comparator Audit | Flagship analysis | Unstable pre-policy comparison blocks causal attribution | Comparator rejected |
| ComplaintFlow | Flagship system prototype | Synthetic fixture validates software behavior, not real-world model performance | Prototype validated; rollout unmeasured |
| Online Shoppers Activation | Completed analysis | Session associations do not establish product impact | Descriptive analysis completed; test proposed |
| Online Retail Customer Growth | Completed analysis | Historical revenue does not establish market attractiveness or profitability | Historical analysis completed |
| Restaurant Quality | Completed analysis | Unadjusted inspection rates support triage, not causal ranking | Triage analysis completed |

Publication requires project-specific results, explicit denominators, reproducibility, limitations, and three validated evidence visuals. See [portfolio-completion-gate-2026-08.md](portfolio-completion-gate-2026-08.md).
