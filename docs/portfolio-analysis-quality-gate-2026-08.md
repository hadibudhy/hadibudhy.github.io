# Portfolio analysis quality gate

This checklist uses objective pass/fail requirements. The current publication decisions are recorded in [portfolio-completion-gate-2026-08.md](portfolio-completion-gate-2026-08.md).

| Requirement | Pass condition |
|---|---|
| Project-specific result | Checked computation or validated system behavior supports the public claim |
| Grain and denominator | Unit of analysis, exclusions, and group counts are explicit |
| Evidence boundary | Observation, inference, causal claim, and proposal are separated |
| Decision use | Recommendation states what the evidence supports and what remains unknown |
| Reproducibility | Source identity and validation path are available |
| Visual evidence | At least three declared evidence visuals support the completed result |
| Artifact status | Completed, proposed, rejected, prototype, or unmeasured status is visible |

Numeric editorial scores are intentionally not used because they can imply external endorsement or precision that the evidence does not provide.
